rabbithole_explorer — feed probe (step 0)

Calls each public feed once from this browser and reports whether the browser may read the response (CORS). Point queries are centred on Nice (43.70 N, 7.27 E), radius 50 nm / 50 km.

Each feed is requested once per click, one at a time, 1.2 s apart (adsb.fi and airplanes.live allow 1 request/s). CelesTrak asks for one download per 2 hours per data set, so this page skips it if it ran less than 2 hours ago.
